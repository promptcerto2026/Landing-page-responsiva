# PromptCerto — Página de Vendas

Página de vendas do e-book **PromptCerto: 50 Prompts que Mudam sua Rotina**.

## 🚀 Como publicar no GitHub Pages

### Passo 1 — Substituir o link da Kiwify
Abra o arquivo `index.html` e substitua **todas** as ocorrências de:
```
https://pay.kiwify.com.br/SEU-LINK-AQUI
```
pelo seu link real da Kiwify. São **4 lugares** no arquivo (use Ctrl+H para substituir todos de uma vez).

### Passo 2 — Criar o repositório no GitHub
1. Acesse [github.com](https://github.com) e faça login
2. Clique em **"New repository"**
3. Nome do repositório: `promptcerto` (ou `seu-usuario.github.io`)
4. Marque como **Public**
5. Clique em **"Create repository"**

### Passo 3 — Fazer upload dos arquivos
1. Na página do repositório, clique em **"uploading an existing file"**
2. Arraste os arquivos: `index.html` e `README.md`
3. Clique em **"Commit changes"**

### Passo 4 — Ativar o GitHub Pages
1. Vá em **Settings** do repositório
2. No menu lateral, clique em **Pages**
3. Em "Source", selecione **Deploy from a branch**
4. Branch: **main** → pasta: **/ (root)**
5. Clique em **Save**

### Passo 5 — Acessar sua página
Após 1-2 minutos, sua página estará disponível em:
```
https://SEU-USUARIO.github.io/promptcerto/
```
